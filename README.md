# Fabralift — ロケットを、最速で組み上げろ。

縦持ち・片手で遊べるドット絵の工場自動化タイムアタックPWA。資源を掘って加工し、ベルトで発射台へ運んでロケットを最速で完成させる。

- 日替わりマップ（全員同じ配置）／練習（ランダム）
- 難易度3段階：やさしい（ガイド・資源無限）／ふつう（資源有限）／むずかしい（結晶・岩・建物上限）
- セーブなし。途中で閉じても自動スナップショットから再開可能（タイムは工場稼働中のみ計測）
- ニックネームでランキング登録（サーバー `rank.php` があればオンライン、なければ端末内）、URL共有で挑戦状
- マスの長押し／マウスを重ねると資源・建物の名前と状態、部品アイコンのタップで作り方を表示
- 初回プレイ時に資源の見分け方を表示
- マップは難易度で 10×14／11×15／12×17、ブリッジで1マス飛び越えて交差可能
- 日本語／English（システム言語に自動追従・タイトルで切替）
- PC操作：マウス（右クリック削除）、`1`〜`6` 建物、`R` 回転、`X` 削除、`Space`/`Esc` 一時停止、`G` ガイド

## 動かし方
静的ファイルのみ。任意のWebサーバーに置くだけで動作（Service Workerのため `https` または `localhost` 推奨）。

```
python3 -m http.server 8000
```

## オンラインランキング（任意・PHP 7.4+）
`rank.php` を同じフォルダに置くだけで有効になります。動かない環境では自動で端末内ランキングに切り替わります。

**データはゲームフォルダの外に保存されます**。ゲームのファイルを差し替え・再アップロードしてもランキングは消えません。

```
public_html/
  fabralift/          ← ゲーム（更新時は丸ごと差し替えてOK）
  fabralift-data/     ← ランキング（自動作成。更新時に触らない・消さない）
```

- 保存先は環境変数 `FABRALIFT_DATA_DIR` で変更可（public_html の外を推奨）
- フォルダには `.htaccess`（外部から読めないように）が自動作成され、書き込みのたびに `.bak` バックアップを残します
- 受け付けるのは当日（±1日）の日替わりマップの記録だけ（練習は対象外）。15秒未満のタイムは拒否し、同じIPからの登録は5秒に1回まで
